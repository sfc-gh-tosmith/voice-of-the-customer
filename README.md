# voice-of-the-customer

This is the code used in the CAA Webinar "Voice of the Customer with AISQL and Snowflake Intelligence". Clone the notebook into your Snowflake account and run it to load in data, process it, and build out a pipeline.

In order to clone the notebook into your account, you'll need to set up a [Snowflake API Integration](https://docs.snowflake.com/en/developer-guide/git/git-setting-up#configure-snowflake-for-access-over-a-public-network)
